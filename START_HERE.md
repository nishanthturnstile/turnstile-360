# Deployment and installation

Use these two guides, in order:

1. [Thaarei ecosystem](docs/deployment/thaarei_ecosystem_guide.md): central host/database,
   staff and MFA, customer registration, catalogues, selected releases, intents and approval.
2. [Customer installation](docs/deployment/customer_deployment_guide.md): DMS/Turnstile,
   private setup inputs, separate Docker Compose, company/users, validation and recovery.

Choose the module POC or full DMS path explicitly. [Titan results](docs/deployment/titan_acceptance_results.md)
record what was actually tested and what remains open. Design stays in [architecture](architecture.md).
This page is a navigation entry, not another setup procedure.
